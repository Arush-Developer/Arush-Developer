### 🐍 Contribution Snake (optional next-level touch)

You can add an animated snake that "eats" your contribution squares. It runs on a GitHub Action, not an external service, so it never breaks:

1. Create `.github/workflows/snake.yml` in a repo named exactly `Arush-Developer` (your profile repo).
2. Use the action from [`Platane/snk`](https://github.com/Platane/snk) — it auto-generates an SVG on a schedule and commits it to an `output` branch.
